TECHNICAL MINDSET

Building robust gameplay foundations through clean software engineering, algorithmic logic, and responsive player controllers.

  • Game Programming & Architecture: Clean, modular, and decoupled C# code adhering to SOLID principles.
  • Gameplay Mechanics: Kinematic character controllers, state machines, inventory engines, and combat logic.
  • Physics & Collision Handling: Custom sweeps, raycasting, trajectory forecasting, and deterministic time scaling.
  • Systems Design: Event buses, scriptable object architectures, and serialization data pipelines.
